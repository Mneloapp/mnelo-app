# Reporting a security issue

Use this repository's private security reporting form:

https://github.com/Mneloapp/mnelo-app/security/advisories/new

Do not disclose an exploitable vulnerability in a public issue. Provide a minimal
reproduction using synthetic accounts, affected source revision/platform, impact
and redacted logs. Never send actual private messages, phone numbers, passwords,
SMS codes, private keys, push tokens or backups. A public-key fingerprint is not
a private key, but use synthetic identities whenever possible.

The current release is under development. There is no security certification,
guaranteed response time, bug bounty or production-support commitment. Open source
enables inspection; it does not itself prove safety. See docs/SECURITY.md and
docs/DELIVERY_ROLLOUT.md for the threat boundaries and known release blockers.
