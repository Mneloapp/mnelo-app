## iOS result and resolved compiler blocker

Selected Xcode is now **26.6 (17F113)**, Swift **6.3.3**, with iOS/Simulator SDK **26.5**. The repository was already SDK 57 in its initial template commit; it was not upgraded from SDK 55 to rationalize the prior report. **26.4+ is Expo SDK 57's published supported minimum**; 26.6 is the version empirically demonstrated here, not a claim that earlier supported versions cannot work. [Official SDK 57 compatibility](https://docs.expo.dev/versions/v57.0.0/).

The historical Xcode 26.2 failure was exit **65** in ExpoModulesJSI's RuntimeScheduler.h shared-reference annotations. Under 26.6, the original lockfile-verified expo-modules-jsi 57.0.8 package compiles its complete simulator framework in 18 seconds, with no source patch or suppressed diagnostics. The failing header is byte-identical to the current 57.1.0 header. This isolates a real compiler/toolchain improvement from the supported maintenance update. [Original failure](PHASE_0_1_REPORT.md), [compiler comparison](audits/ios-26.6/header-probe.json).

Xcode's missing iOS platform component was downloaded officially. A duplicate CoreSimulator registration was repaired while preserving the runtime asset and device data. The full app compiled in **837.79 seconds, zero errors / 955 warnings**. That diagnostic build had signing disabled and failed native Keychain initialization at runtime (-34018). A normal simulator ad-hoc signing rebuild passed in **44.56 seconds, zero errors / 519 warnings**, verified its signature and successfully booted. SecureStore was not weakened or replaced. [Full build and runtime record](BUILD_LOG.md), [machine-readable result](audits/ios-26.6/native-result.json).

## Security and dependency disposition

RLS, explicit grants and live-session checks protect exposed application tables, private Storage and Realtime. Verified negative cases cover private phone/profile fields, unrelated conversations/messages/attachments, blocked discovery/requests/chat, self-verification/reputation, admin actions, reports, device tokens, unauthorized LiveKit tokens and exact-location leakage. Private media access is time-limited and policy-checked; exact GPS is only deliberately shared inside authorized conversations. Blocking/reporting and service-only moderation boundaries are implemented. [Security matrix](SECURITY_TEST_MATRIX.md), [RLS matrix](RLS_MATRIX.md).

History/source/exported-bundle scans report zero findings. The actual standalone embedded Android bundle and extracted strings also pass the redacted secret scan. This is not a guarantee against every encoded secret. Local server credential files are ignored and private. V1 has **no E2EE claim**; server-readable messages, signed-URL expiry, inability to recall copied data and future encryption boundaries are documented.

Final npm audit: **16 moderate affected-package entries, zero high/critical, two underlying advisories**; Deno server lockfile: **zero known vulnerabilities at the September 8 audit**, with the server dependency graph unchanged. The [complete package-by-package audit](DEPENDENCY_AUDIT.md) records direct/transitive status, runtime exposure, fixes and breaking impact. Thirteen inherited UUID build-tool entries are accepted for the inspected controlled-input usage. Three decoder-related runtime entries remain on the release risk register: launch-only input mitigation passed installed-router tests and actual Android standalone cold/warm checks, and actual iOS standalone cold/warm checks now pass too; the vulnerable package remains installed and final distribution/physical acceptance remains required. No safe nonbreaking fix was available in the dry-run; no force upgrade, advisory suppression or SDK major change was applied.

Cloud perimeter/SMS abuse controls, operational moderation/filtering, provider monitoring, hardware/background calls, deployed retention/backup settings and final legal review remain release work. No deployed malware scanner, full DDoS protection, independent penetration test or OS/container-wide security certification is claimed.
