**Visual regressions found and fixed on the native development app. Cross-platform and physical-device acceptance remains open.** This is a fresh interaction pass against the real, isolated local Supabase backend, following the approved-brand implementation at `4ff7f2dfcffb95247e7c68a0b9eb04ee8cc62b69`. ## Fixed findings

| Finding observed in the app                                                                  | Final correction and evidence                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Country picker title/close overlapped the iPhone clock and status area.                      | A modal-local SafeAreaProvider now supplies the correct native insets. The native Georgian request → interpretation → 3 real results → profile → connection request flow succeeded after the fix.     |

No deleted profile identity is invented.                                                                                                                                                                                                                               |

Long Georgian contact names, files, image, voice and location content were re-inspected on the compact iPhone.                                                                                                                                                                                              |
| Large-text headers, timestamps and choices competed for limited width.                       | On compact screens the chat avatar is omitted, titles have two lines, large-text call actions occupy a separate row, inbox timestamps move below preview text, and choices stack vertically. Back-navigation headers use a compact base type style while retaining OS scaling. Georgian Requests no longer strands its last letter on another line at the tested size.                                      |

Groups/deleted titles are excluded. RLS-denied peers are omitted; network failures remain visible errors. Three focused tests cover order, bounded reads, access changes and error propagation.                                                                                                                         |
| Group/contact selection had no accessible selected state; contact search could appear blank. | Shared rows expose selection state; both native pickers were checked. Contact search exposes loading/no-results feedback. Changing its query clears the previous selection so a hidden contact cannot remain the Send target. | Denying contact permission incorrectly reported a service outage.                            | Check actual OS permission after a picker/read failure and provide localized recovery guidance. No broader permission request or address-book upload was added. Native denial and invitation share-sheet recovery were verified; four tests distinguish cancel, selected-name read, denial and unrelated failures.                                                                                          |
| Uploading still allowed cancellation of the selected file or editing its caption.            | Conflicting media/recording controls and fields are disabled while sending; account-deletion confirmation and Cancel are likewise disabled during the request. Choose/camera controls retain their labels instead of displaying additional send spinners. During a real temporary local-service interruption, selected-file Cancel and caption were disabled and the pending upload subsequently completed. |

Hermes evidence: the installed native runtime reproduced the missing method, and the [official Hermes Intl API table](https://github.com/facebook/hermes/blob/static_h/doc/IntlAPIs.md) lists NumberFormat `formatToParts` as Android-only. The first crash display had an obsolete Metro source mapping; restarting Metro with a cleared cache exposed the correct `formatNumber → MatchReason` stack. No compiler, dependency or generated native-code workaround was used. The country-modal correction follows the library’s [official guidance on modal-local safe-area providers](https://appandflow.github.io/react-native-safe-area-context/api/safe-area-provider/).

## Test data, safety and remaining acceptance

The disposable signup account was deleted through the app and guarded worker; the primary QA account and its conversations were preserved. All new people, requests, messages, group, avatar and review used loopback-only **Mnelo Development** fixtures. Credentials stayed in memory/ignored server environment files and were never printed or committed. The two temporary gateway pauses each automatically resumed; no gateway remains paused. The local functions server was restarted because it was initially absent (HTTP 503); real uploads/calls then worked. Temporary fixture/driver scripts and raw native logs remain in ignored `artifacts/visual-qa`. No Supabase production project or external identity was touched.

**Still open:** complete interactive Android regression, manual VoiceOver/TalkBack, physical camera/GPS/notifications, two physical call participants, background interruptions and airplane-mode/reconnect. The running Android emulator is absent from the native UI tool's application inventory; direct lookup returns `Invalid app: qemu-system-aarch64`. Its build/install/render/log checks succeeded, but further actions were not fabricated or replaced with a different platform's results. Physical iPhone testing remains deferred per the owner.

This pass substantially expands the earlier identity-only QA. It does not assert that every combinatorial screen/state/font/device permutation was executed, or certify TestFlight/store readiness. **Release recommendation remains NOT READY** pending the documented physical/cloud/security release gates. The corrected design is ready for the next supervised device QA round.
