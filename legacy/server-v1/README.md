# Retired server-persistence product surfaces

These source files are preserved only as migration/history evidence. The owner removed Connect, Need/Offer, matching, contextual commercial connections and reputation from the product on 2026-09-10. They are not Expo routes, are not imported by the active app, and must not be reactivated through a backend configuration switch.

The active product is a device-owned messenger with Chats and Me. Direct/group conversations and calls use participant-owned copies. Local deletion must never delete a peer's copy. No old Supabase/RLS test is proof of the new storage/transport privacy guarantee.

The old database migration history and denial tests remain available for reviewing the superseded implementation. No Git history or old commit message has been rewritten. This directory is not a second supported app or a deployment target.
